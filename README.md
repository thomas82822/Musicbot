## 🚀 Deploy Karo

### Method 1 — Heroku (One-Click Deploy) ⭐ Recommended

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/thomas91929/Musicbot)

> **Heroku deploy karne ke baad ye env vars zaroor set karo:**
> `API_ID`, `API_HASH`, `BOT_TOKEN`, `SESSION_STRING`, `OWNER_ID`

### Method 2 — Railway / Render

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/thomas91929/Musicbot)

1. Repo fork karo
2. Platform pe connect karo  
3. Environment variables set karo (neeche table mein)
4. Deploy!

### Method 3 — VPS / Local

```bash
# Repo clone karo
git clone https://github.com/thomas91929/Musicbot
cd Musicbot

# Dependencies install karo
pip install -r requirements.txt

# .env file banao (ya env vars set karo)
cp .env.example .env
nano .env

# Bot chalao
python main.py
```

## ⚙️ Configuration

`.env` file mein ya platform ke environment variables mein ye values set karo:

### ✅ Required

| Variable | Description | Kahan milega |
|----------|-------------|--------------|
| `API_ID` | Telegram API ID | [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | Telegram API Hash | [my.telegram.org](https://my.telegram.org) |
| `BOT_TOKEN` | Bot token | [@BotFather](https://t.me/BotFather) |
| `SESSION_STRING` | Userbot session | [@StringFatherBot](https://t.me/StringFatherBot) ya `python SESSION_STRING_HELPER.py` |
| `OWNER_ID` | Tera Telegram User ID | [@userinfobot](https://t.me/userinfobot) |

### ⚙️ Optional (Recommended)

| Variable | Description | Default |
|----------|-------------|---------|
| `LOG_CHANNEL` | Bot logs channel ID | — |
| `SUPPORT_CHAT` | Support group link | — |
| `OWNER_USERNAME` | Tera username (without @) | — |
| `BOT_NAME` | Bot ka naam | `🎵 Music Bot` |
| `BOT_VERSION` | Version string | `v1.0` |
| `GITHUB_TOKEN` | Data sync ke liye PAT | — |
| `BOT_REPO` | GitHub repo for data | — |
| `MUST_JOIN` | Force join channel | — |

### Session String Generate Karo

```bash
cd Musicbot
python SESSION_STRING_HELPER.py
```

## 📁 Project Structure

```
Musicbot/
├── main.py              # Bot entry point
├── config.py            # Configuration loader
├── database.py          # JSON-based database

│
├── plugins/             # All command handlers
```
